
# Simple Line Editor in C

## Project Description
This project is a simple command-line text editor developed using C.
It allows users to insert, delete, display, save and load text lines.

## Features Implemented

### Core Features
1. Insert a line
2. Delete a line
3. Display the document
4. Save and load a file1

### Bonus Features
5. Search for a word
6. Count lines and words

## Data Structure
An array of strings is used to store the document lines.

## Technologies Used
- C Programming
- VS Code
- GCC Compiler

## How to Compile

gcc main.c -o editor

## How to Run

.\editor

## File Storage
The document is saved in document.txt.
The saved document is automatically loaded when the program starts.
