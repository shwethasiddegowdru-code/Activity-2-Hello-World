
# SIMPLE LINE EDITOR - HELP

## Introduction
This is a simple line editor developed using C.
It allows users to create and manage text documents.

## Available Commands

### 1. Insert Line
Adds a new line at the given line number.

Example:
Enter line number: 1
Enter text: Hello World

### 2. Delete Line
Deletes a particular line from the document.

Example:
Enter line number: 1

### 3. Display Document
Displays all lines with their line numbers.

### 4. Save Document
Saves all lines into document.txt.

### 5. Load Document
Loads previously saved text from document.txt.

### 6. Search Word
Searches for a word and displays the line numbers where it is found.

Example:
Enter word: Hello

### 7. Count Lines and Words
Displays the total number of lines and words.

### 8. Exit
Saves the document and closes the editor.

## Compilation

gcc main.c -o editor

## Execution

Windows:
.\editor
